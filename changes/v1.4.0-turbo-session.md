# v1.4.0 - Turbo Session
## Fitur baru (1 fitur = 1 modul)
- feature/turbo: TurboService (foreground) + layar kontrol, tombol Stop di notifikasi
- feature/memoryguard: cek RAM tiap 30 dtk, tutup proses latar jika RAM kosong < 20% (game dikecualikan)
- feature/heatguard: suhu >= 43C -> getar + turunkan kecerahan bertahap; pulih saat < 40C
- feature/networkguard: Wi-Fi lock performa, matikan auto-sync, ping langsung
- feature/advisor: saran grafis sesuai kelas HP
- core/SessionRestore: simpan & pulihkan kecerahan, sync, Mode Fokus (juga setelah crash, dicek saat app dibuka)
- core/TurboState: state bersama service-UI-HUD
## Perubahan
- Boost & Play kini memulai Turbo Session (urutan: bersihkan RAM -> snapshot -> Mode Fokus -> buka game)
- HUD: tanpa Choreographer (tidak lagi membangunkan CPU tiap frame), update 1x/detik, tambah ping, merah saat panas/lag
- Tools: tab baru Turbo (paling kiri)
## Izin baru
WAKE_LOCK (batas 4 jam), VIBRATE, WRITE_SYNC_SETTINGS, CHANGE_WIFI_STATE, WRITE_SETTINGS (opsional, diberi user lewat layar sistem)
## Security
- Service exported=false; semua perubahan sistem dipulihkan saat Stop/crash; wake lock punya timeout; perubahan kecerahan hanya jika user memberi izin
