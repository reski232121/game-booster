# v1.1.0 - Tools
## Fitur baru (1 fitur = 1 file/modul)
- feature/crosshair: crosshair overlay (titik/plus/lingkaran)
- feature/hud: HUD melayang (refresh layar, RAM, suhu)
- feature/overlay: service foreground + layar kontrol
- feature/timer: timer main + pengingat istirahat 1 jam
- feature/notes: catatan sensitivitas/setting per game
- feature/tools: tab Tools menampung Overlay, Timer, Catatan, Device
## Perubahan struktur (dilaporkan)
- Tab "Device" di bottom bar dipindah ke dalam Tools (DeviceScreen tidak diubah)
## Security
- Service exported=false, overlay NOT_TOUCHABLE, izin overlay hanya diminta saat user menyalakan toggle
- usesCleartextTraffic=false eksplisit; input catatan disanitasi
- Tidak ada izin baru selain overlay & foreground service
